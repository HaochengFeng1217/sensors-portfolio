# Single LED PWM fade

- Tested on the classic ESP32 Dev Module using Arduino IDE 2.3.11.
- Reported wiring: GPIO16 through a 220-ohm resistor to the red LED anode; cathode to GND.
- task1-led.ino is the final restored fade sketch; diagnostics/gpio16-blink is an earlier on/off test, not the final experiment.
- Preserve the recorded video. Do not claim a measured PWM frequency or cycle duration.
- Record IDE assistance and unverified wiring values honestly. Documentation is English.
