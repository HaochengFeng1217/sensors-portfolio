# Wokwi mini-exercise

Status: **Not started. This folder is an evidence plan, not a completed experiment.**

1. Open [Wokwi](https://wokwi.com/) and create an ESP32 Arduino/C++ project.
2. Add a potentiometer and connect it to an analog input.
3. Read the input and print it with `Serial.println(...)`.
4. Make the input change an LED output.
5. Run it, change the ADC resolution, and record what actually changes.
6. Test a deliberately coarse threshold or step.
7. Save the project link and/or actual circuit and serial-output screenshots.

Save real source files here when created. Put screenshots in [../images/](../images/README.md).
Record observations in [the Module 0 entry](../README.md).
